## 1. Agent 入口说明

| 入口 | 说明 |
|---|---|
| 本地运行 | `npm run setup && npm start` → 浏览器打开 **http://localhost:8787**（README 有 3 步指引） |
| 交互形态 | 豆包式对话智能体：输入框即入口，欢迎页带 4 个示例引导词，左栏 6 张技能卡一键直调 |
| API 入口 | `POST /api/chat`（SSE 对话）· `POST /api/agents/onecrew/run`（直接起工作流）· `POST /api/skills/:id/run`（单技能），共 16 个接口，契约见《01-调研与设计文稿》第 7 节 |

无账号、无配置门槛：不填模型 Key 自动进入演示模式（确定性产出），评审零成本复核。

## 2. 核心能力、输入输出与调用方式

### 2.1 一键工作流（主能力）

输入一句话（如"我的产品是智能保温杯，想卖日本，帮我出全套出海内容"），
Agent 按 `agents/onecrew.agent.json` 定义执行 7 步状态机：

| 步骤 | 类型 | 产出工件（exports/ 落盘） |
|---|---|---|
| 1 市场快研 | skill | 市场快研报告.md |
| 2 市场选择确认 | **confirm（人工）** | —（批准继续 / 驳回终止） |
| 3 品牌声音定位 | skill | 品牌声音档案.json（可校验 JSON） |
| 4 五平台文案 | skill | 五平台文案包.md（X/IG/TikTok/LinkedIn/PH） |
| 5 图像提示词 | skill | 图像提示词包.md（MJ/即梦/SD 三套） |
| 6 7天内容日历 | skill | 7天内容日历.csv（UTF-8 BOM，Excel 直开） |
| 7 合规体检 | skill | 合规体检清单.md |

### 2.2 六技能（可独立调用）

每技能一个 `skills/<id>.json` 工作流文件（Wave2 沉淀），含输入 schema、提示词模板、输出格式约定：

| 技能 | 输入 | 输出 |
|---|---|---|
| market-scan 市场快研 | 产品、目标市场(可省) | 市场/平台/竞品/定价报告 |
| brand-voice 品牌声音官 | 产品 | 人设/语气/用词红绿灯/口号 JSON |
| copy-studio 文案流水线 | 产品、市场、语言 | 五平台原生格式文案包 |
| visual-prompt 提示词工坊 | 产品、场景 | 三套文生图提示词（不产成片） |
| content-calendar 内容日历 | 产品、市场 | 7 天排期 CSV |
| local-check 合规体检 | 市场、产品 | 合规/禁忌/节日清单 |

### 2.3 运行控制（L10 规格全量实现）

- **进度可视**：右栏步骤时间线，每步状态/耗时/产出实时 SSE 推送；
- **人工确认点**：confirm 步骤挂起等待批准，批准继续、驳回终止（窗口关闭后重进仍可批，run 落盘）；
- **取消/重跑**：运行中可停；失败/取消可重跑，重跑生成新 run（旧 run 保留作审计）；
- **全程留痕**：`data/runs/*.json` 不可变记录（每步状态/起止时间/工件索引），评审可直接打开复核。

### 2.4 调用方式（对话即调用）

- 直接说需求 → 意图路由器（关键词 + LLM 兜底分类）自动挂载技能或工作流；
- 点技能卡 → 模板填空；
- HTTP API → 任意第三方可复用（SSE 事件：`start/token/step/artifact/run/done/error`）。

## 4. 与前两轮（Specs / Skills）相比的关键更新

Wave 1（Specs）产出需求确认单与 11 节设计规格；Wave 2（Skills）产出六技能的提示词与工作流文件。
**Wave 3 新增的是"让它们真正跑起来"的完整智能体系统**：

1. **对话编排引擎**：豆包式流式对话 + 意图路由器，把静态技能文件变成"说一句话就执行"的智能体；
2. **状态机执行器**（L10 全量）：步骤推进 / 人工确认点 / 取消 / 重跑 / 失败记录，全事件 SSE 实时推送；
3. **工件系统**：产出物结构化落盘（MD/CSV/JSON），可预览可下载，CSV 直接可导入排期工具；
4. **可复核留痕**：runs 不可变 JSON，每一步谁跑的/何时/结果可查——评审证据链闭环；
5. **双 Provider 降级**：真实 LLM 优先，失败或无 Key 自动降级确定性 Mock，演示永不空场；
6. **H8 安全闸**：生成内容过本地敏感词拦截后才产出（v2 接云端审核）。

一句话：**前两轮证明"我们知道该做什么"；本轮证明"它真的能跑、能交付、可复核"。**
