## 3. 差异化叙事（1 分钟）

- **对手做到「内容」为止，OneCrew 做到「成交」为止。** 同类工具给你文案模板；我们的一条流水线从市场调研 → 品牌 → 文案 → **图** → **成片** → 日历 → 合规，产物直接可发。
- **合规体检是我们踩出来的差异化。** 调研确认 8 家竞品 0 家覆盖；这是跨境卖家最痛的坑（78% 搞不定、近 40% 首年被限权/封号），也是大厂「不敢做」的脏活——单人团队反而能快速迭代。
- **成本账透明到分。** 每次运行在 data/runs 真实记账，前端「成本」页签直接看：10 次全流程 ¥1.32。对照 UGC 外包 $45-212/条、代运营 ¥5k-30k/月——这是 1/100 量级。

## 4. 技术亮点（1 分钟，评委常问）

1. **Agent 图谱执行器**：9 步状态机 + append-only 事件日志（每步落盘，评审可复核 `data/runs/*.json` 61 条事件）。
2. **上下文接力**：每步工件摘要注入下游 context——短片导演直接复用视觉工坊的 4 张图；合规体检审的是真实产出。这是行业 demo 常见的「各步独立、伪协作」的正解。
3. **媒体工程**：火山 Seedream 4.0 生图（0.2 元/张）+ Edge TTS 免费配音 + 自研 ffmpeg 合成层（Ken Burns/xfade/ASS 字幕/ducking），1080×1920 成片 14 秒出片。
4. **可靠性设计**：推理模型偶发不输出 JSON → 双重试 + 结构校验 + 确定性 mock 兜底；无生图 Key 自动降级「构图小样」并明示——**全流程永不中断，这是可上线产品与 demo 的分水岭**。
