## 0 · 一页结论（TL;DR）

**定位一句话：** 大公司有 agency，一人公司有 OneCrew —— 把"研究→定位→创作→排期→合规"全链条装进一个**可复核**的对话式智能体，并且是全网此类产品中**唯一内置"出海合规体检"环节**的。

**三个站得住的差异点（📎 调研结论）：**
1. **合规体检环节 = 行业空白**。FTC 2023 修订《Endorsement Guides》、2024-08 强化品牌对达人的监督义务，EU DSA/AI Act 增加内容标识义务；调研的所有竞品（Ocoya/Predis/Jasper/Copy.ai/Simplified/Taplio…）无一提供"文化禁忌/广告法体检"，最接近的只是 HoppyCopy 的邮件 Spam Check。
2. **可复核执行引擎**。状态机六态＋不可变 run＋人工确认＋工件落盘＋双 Provider 降级＋16 个 API——对比之下，同台 7 支队伍全是 workflow agent，绝大多数是"黑盒 prompt 编排"。我们的每一步可打开 `data/runs/*.json` 逐条核对。
3. **全链条 + 中文出海双语境**。竞品要么单点（Taplio 只做 X/LinkedIn，HoppyCopy 只做邮件），要么 $1,000/月把一人公司挡在门外（Copy.ai Workflow 起步价）；"中文用户做海外内容"的跨文化转译无人认真做。

**两个必须诚实面对的弱项（📎）：**
1. **无发布闭环**：产出只到 CSV 就断了，Simplified / Predis.ai 有真实 auto-post 与效果回流——"最后一公里"是留存钩子。
2. **无数据壁垒**：Taplio 有 6 万帖/月基准库、Copy.ai 有 GTM 数据层；我们的研究深度依赖通用 LLM，需靠"可复核引用"对冲。

**本报告最重要的三个新发现：**
1. **时间线（✅ 亲手核验官方活动页）**：提交 8/31 已结束、交叉评测 9/1 已结束、**今天 9/2 是"评审与结果发布"日（Active）**，AI 评审此刻正在读平台仓库 `linxi/NINE` 与全部辩论内容；**9/4–9/6 雪窦山总决赛协创松 Buildathon（48 小时封闭迭代＋路演＋颁奖）**。我们的"赛前修改窗口"就是 9/2→9/4 的 48 小时，且下一关交付物是 Wave 4。
2. **交叉评测致命批评（✅ 平台 Issue #1 全文）**：chozzc（Allweave 作者，9/1 23:26）从执行代码指出：**六个技能各自独立运行、没有消费上游工件**——"六位队友接力"的叙事目前技术上不成立（详见 §3）。这是 P0 修复项，也是辩论回应的必答题（辩论内容直接进 AI 评分）。
3. **竞技态势（✅ 官方页名单）**：7 支同台队伍全部是 workflow/agent 类（同质化严重）；其中 **Allweave（allweave.chozzc.dev）和 CultureOS（culture-os.shuntian.uk）有在线可点的 Demo**，我们只有 GitHub 仓库链接——"点开即玩"这一项我们已经落后，必须补在线部署或演示视频。

**功能取舍一句话结论（详见 §7）：**
- **删**：重复调试工件、9 字节残缺文件导读绕开、`index.js` 平行 `streamChat` 实现、`App.jsx:264` 的 `|| true` bug。
- **减**："演示模式"从卖点降级为脚注，README 首屏改为直接展示 real 模式代表工件，避免"Mock 嫌疑"。
- **加（P0，48h 内）**：① 技能上下文接力（让"接力"为真，同时回应 chozzc）② 可编辑确认点（改市场/语言再放行）③ 单工件重新生成（补齐官方任务原文"生成、筛选、修正、导出"的后两字）④ 真实成本账（从 `data/runs` 汇总 token/耗时/折算成本）⑤ README 顶部"真实运行凭证"导读区块。
- **上线可用还差（P1+）**：发布通道（哪怕先做"一键复制到平台格式"）、文生图 API 闭环、用户系统与鉴权、append-only 事件日志。

PH 趋势：Averi（"AI marketing manager"）、Simplified Riley、Taplio/Typefully 上 MCP——"AI marketer agent"是 2025–2026 明确趋势，说明方向对、且赛道正快速拥挤（紧迫性论据）。

### 4.2 空白验证结论

"以一人公司为主体、研究→定位→创作→排期→合规全链条、对话式 Agent"**基本成立但非绝对空白**：Simplified 叙事几乎同构（且有真实发布），Lindy $30/月能搭近似流程。**真正无人占位的是合规体检环节**；其次是我们"每一步可复核"的工程取向（竞品全是黑盒）。

### 4.3 市场硬数字弹药（路演用，带来源）

- **29.8M** 美国非雇员企业（一人公司主体口径，2023 NES，Census 2025-05 发布）→ census.gov/library/stories/2025/07/nonemployer-business-growth.html
- **2.63 万亿元** 2024 中国跨境电商进出口额，+10.8%，出口首破 2 万亿 → 海关总署/国新办（english.scio.gov.cn）
- 代理公司 retainer 常规 **$2,500–10,000+/月**，内容营销代理约 **$3,500–5,000/月**（clicksgeek 2026 指南等）vs 同类 AI 工具 solo 价 **$15–79/月** → **代理费的 1/40–1/100，这是成本叙事核心**
- 全球 solo business 总数口径混乱未核实，**只用美国 Census 数**。

## 5 · 评委视角：四维评分逐项拆解 📎（对照官方原文）

> 官方四维：创新性与技术含量 30% / AI+OPC 模式可行性 30% / 市场潜力与社会价值 30% / 落地海外市场可行性 10%。官方 W3 任务原文四个关键词：**可交互、可运行、可复用、稳定产出可验证结果**。

### 维度一 创新性与技术含量（30%）
- **强**：证据链完整度在 7 队中稀缺（状态机六态、不可变 run、SSE 全事件、确认点、双 Provider、9 个 run 留痕其中 1 个 canceled 恰好证明取消功能真跑过）；"可复用"有硬证据（技能 JSON 运行时加载＋16 API）。
- **弱**：①意图路由朴素（关键词＋LLM 兜底），无 RAG/记忆/工具调用——技术叙事必须压在"可复核执行引擎"而非"会调 LLM"；②零测试；③**切题度风险**：赛道官方定位"聚焦图片/视频/音乐/3D 大模型子赛道"，我们不调生成模型本体只产提示词——这是评委最自然的第一问（应对话术见 §8 风险 4）。

### 维度二 AI+OPC 模式可行性（30%）
- 官方定义逐字：**"项目架构是否真正体现'单人+AI'的高效协同，人力与 AI 分工是否合理"**——评委查分工设计。
- **强**：确认点即分工的具象化；"一人＋OneCrew＝六人小队"映射清晰。
- **弱**：①**成本账是空话**（"数万降到近零"无数字支撑，而 data/runs 里的耗时/调用记录就是现成算账素材）；②官方 W3 动作链原文"**生成、筛选、修正、导出**"——我们生成/导出满分，筛选（多候选择优）与修正（单步重生成）缺失，只有 run 级重跑与驳回终止；③零真实用户证据。

### 维度三 市场潜力与社会价值（30%）
- **强**：竞品空白分析结构化（同类提交少见）；"大公司有 agency，一人公司有 OneCrew"一句话叙事强；与大赛语境共振（承办方原话"全球抢真实企业订单"，协办含"上海市数字企业出海服务协会"，30 万奖励＝真实业务合同——出海正是主办方要的方向）。
- **弱**：①此前市场判断零数字零来源（本报告 §4.3 已补）；②没有真实产品案例——所有演示基于虚构"智能保温杯"，而奖励是"真实业务合同"，评委真正想知道"明天能不能接单交付"；**拿 1 个真实存在的产品跑一遍全流程并公开产出包，是本维度性价比最高的补强**；③平权叙事无可验证落点。

### 维度四 落地海外市场可行性（10%）
- **强**：五平台原生格式＋多语言＋海外云零改造部署（Node＋静态前端＋OpenAI 兼容 API）；Provider 可切换（双 Provider 架构支撑）。
- **弱**：①产出未经真实平台验证（X 字数/PH 格式是 LLM 说的"应当如此"）；②默认 LLM 供应商 api.b.ai 的海外可用性未论证（材料应写明 Provider 可切换）；③总决赛口径下"落地临港/OPC 认定意愿"零提及——**必须补一段**。

### 胜负手排序

**最易扣分**（按杀伤力）：1) "只是 prompt 编排"质疑 → 用可复核引擎对冲；2) Mock 嫌疑 → 证据导读（评委先看到能力列表而不是真实凭证，组织顺序错了）；3) 没有点开即玩的 Demo（对手两家有）；4) 切题度；5) 按自设 9 条验收标准实测翻车（尤其"拔 Key 出横幅/CSV Excel 不乱码/前端 grep 不到 key"三条）。

**最易加分**：1) 在线 Demo URL（免费部署即可）；2) 真实成本账（全场大概率没人有）；3) 补"筛选、修正"两动作（逐字对题）；4) 真实产品完整产出包 case study；5) 交叉评测辩论回复质量（零开发成本的持续加分动作）。

## 6 · 差异化定位与路演讲稿

### 6.1 主打什么（PPT 三页核心）

1. **页一（痛点）**：一人公司出海内容的三重墙——翻译软件没品牌感、agency 五位数起、ChatGPT 每次从零聊。硬数字：2.63 万亿中国跨境电商盘子 vs 一个人雇不起内容团队。
2. **页二（方案）**：六位 AI 队友接力交付全套装出海内容包，3 分钟、几毛钱 token；**三大差异点**：全链条含合规体检（行业唯一）/ 每步可复核（审计级留痕）/ 技能文件化（改技能不改代码）。
3. **页三（可行性与账）**：海外云零改造；成本账＝外包 $3,500–5,000/月 → OneCrew 全流程 ≈ 一杯咖啡的零头；前十名可接真实业务合同——OneCrew 本身就是为抢订单准备的工具。

### 6.2 三分钟路演逐字稿（总决赛协创松适用）

- **痛点（20s）**："全球每天有上万个产品想出海，但 99% 的一人公司雇不起内容团队——翻译软件给不了品牌感，agency 开价五位数起。出海内容，是 OPC 最贵的一道墙。"
- **方案（30s）**："OneCrew 把六位 AI 队友装进一个对话框：你只说一句'我的产品是保温杯，想卖日本'，市场分析师、品牌官、文案、视觉总监、运营、法务六人接力，3 分钟交付一套可直接落地的出海内容包。"
- **演示（40s）**："请看三个细节：第一，这里有个市场确认点——AI 主打、人拍板，这是我们对'人力与 AI 分工'的回答；第二，每一步的状态、耗时、产物全部落盘留痕，各位现在就可以打开 data/runs 目录逐条复核；第三，断网无 Key 它也能跑完整全流程——演示永不空场。"
- **差异化（25s）**："Jasper 只会写文案，Buffer 只管排期，ChatGPT 每次从零聊。OneCrew 卡位的是空白：研究、定位、创作、排期、合规全链条装进一个可复核的智能体，六项技能全部文件化——改技能不改代码。"
- **可行性（20s）**："技术栈海外云零改造可部署；全流程成本是几毛钱的 token；我们把 Wave 1 定的九条验收标准逐条跑通——评测可以按我们自己的标准来查。"
- **成本账收尾（15s）**："过去这套内容外包要三万块，OneCrew 把它压到一杯咖啡的零头；大赛前十名就有机会接真实业务合同——OneCrew 本身，就是为'抢订单'准备的工具。"

> 结构要点：演示段**主动替评委说出他们最想挑刺的三件事**（人机分工、真实性、降级），把质疑变成展示点。若"接力"修复完成，方案段改为"每一位队友都在上一位队友的结论上继续工作——市场报告确认后，品牌官基于它定声音，文案基于它写稿，法务拿着成稿做体检"——这句在修复后就是真的，且正面回应 chozzc。
