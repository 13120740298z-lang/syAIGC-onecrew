## 方案 A（首选）：香港轻量应用服务器 · 直装 Node

### A1. 购买（约 5 分钟）
1. 打开腾讯云轻量应用服务器：<https://cloud.tencent.com/product/lighthouse>（阿里云同理：<https://www.aliyun.com/product/swas>）
2. 选 **中国香港** 地域 → 镜像选 **Ubuntu Server 24.04 LTS**（或 22.04）→ 套餐选最低配 **2核2G** 即可（ffmpeg 编码 15 秒片约 20-40 秒，够用）。
3. 支付宝/微信支付均可。首次使用需实名认证（个人即可）。
4. 购买后在控制台 → 防火墙 放行端口：`22, 80, 443, 8787`。

### A2. 连接与安装（SSH）
```bash
ssh ubuntu@<服务器公网IP>   # 轻量默认普通用户；sudo -i 切 root
```
```bash
apt update && apt install -y curl git fonts-noto-cjk
curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt install -y nodejs
node -v && ffmpeg -version 2>/dev/null || echo "(用 ffmpeg-static 自带，无需系统 ffmpeg)"
```
> `fonts-noto-cjk` 必装：ASS 字幕烧录依赖 Noto Sans CJK SC（ffmpeg.js 里字体名写死了）。漏装 = 字幕变方框。

### A3. 拉代码
```bash
mkdir -p /opt/onecrew && cd /opt/onecrew
# 方式一：git 拉取（推荐）
git clone <你的仓库地址> .
# 方式二：本机直接推整个目录（Windows PowerShell 里执行）
# scp -r server skills agents prompts web/dist assets package.json package-lock.json root@<IP>:/opt/onecrew/
npm install --omit=dev
```
> npm install 会自动下载 **Linux 版 ffmpeg-static 二进制**（重装即可换平台，无需手工处理）。

### A4. 配置密钥（服务器本地，永不入库）
```bash
cd /opt/onecrew
cat > server/.env <<'EOF'
LLM_BASE_URL=<你的 api.b.ai 地址>
LLM_API_KEY=<你的 Key>
LLM_MODEL=deepseek-v4-flash
EOF
chmod 600 server/.env
```
（可选生图/TTS：`ARK_API_KEY` / `SILICONFLOW_API_KEY`，不配则自动降级本地构图小样 + Edge TTS。）

### A5. 常驻进程 + 开机自启
```bash
cat > /etc/systemd/system/onecrew.service <<'EOF'
[Unit]
Description=OneCrew AIGC Content Agent
After=network.target

[Service]
WorkingDirectory=/opt/onecrew
ExecStart=/usr/bin/node server/index.js
Environment=NODE_ENV=production
Restart=always
RestartSec=3

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now onecrew
systemctl status onecrew --no-pager | head -8
curl -s http://localhost:8787/api/health
```

### A6. 验收
- 浏览器打开 `http://<公网IP>:8787` → 应看到 OneCrew 首页，左下角「● 真实模型 deepseek-v4-flash」。
- 跑一条全流程：`我的产品是智能保温杯，316不锈钢12小时保温，想卖日本` → 9 步全绿，工件含 4 张图 + 1 条 MP4。
- 手机制 4G 网络（非 WiFi）再开一次，确认公网真实可访问。

### A7.（可选）80 端口 + 域名
```bash
apt install -y nginx
cat > /etc/nginx/sites-available/onecrew <<'EOF'
server {
  listen 80 default_server;
  location / { proxy_pass http://127.0.0.1:8787; proxy_http_version 1.1;
    proxy_set_header Connection ''; proxy_buffering off; proxy_read_timeout 600s; }
}
EOF
ln -sf /etc/nginx/sites-available/onecrew /etc/nginx/sites-enabled/ && rm -f /etc/nginx/sites-enabled/default && systemctl reload nginx
```
> nginx 反代必须 `proxy_buffering off`，否则 SSE 步骤流会被缓冲成「卡住不动」。

## 方案 B（备选）：Sealos 容器（2核2G 常驻 ≈ ¥60-70/月）
适合不想管服务器的场景，但需先构建 Docker 镜像（本项目未含 Dockerfile；需要时可加：FROM node:22-slim + apt fonts-noto-cjk + npm install）。密钥用 Sealos 的环境变量注入，不落盘。缺点：无 SSH、ffmpeg 临时文件需挂载存储卷（另计费），叠加后不比轻量服务器便宜。

## 方案 C（兜底）：cpolar 隧道（路演现场断网应急）
本机起服务 + `cpolar http 8787` 得临时公网 URL。免费版仅 1Mbps 带宽 + 随机域名，视频会卡；仅作演示文稿/文档页兜底，不作媒体演示。

## 出问题查这里
| 症状 | 原因 | 处理 |
|---|---|---|
| 页面开了但步骤不动 | nginx 缓冲 SSE | 加 `proxy_buffering off`（见 A7） |
| 视频字幕全是方框 | 缺 CJK 字体 | `apt install fonts-noto-cjk` 后重启服务 |
| 视频合成报 exit 1 | 无 ffmpeg | npm 重装依赖（ffmpeg-static 会拉平台二进制） |
| 显示「演示模式」 | server/.env 没读到 | 确认路径 `/opt/onecrew/server/.env`、`chmod 600`、`systemctl restart onecrew` |
| 生图报 LOCAL_FALLBACK | 未配 ARK/SF Key | 配上即真图；不配则演示小样（明示），流程不中断 |
