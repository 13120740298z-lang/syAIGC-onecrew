## 3. 差异化叙事（1 分钟）

- **对手做到「内容」为止，OneCrew 做到「成交」为止。** 同类工具给你文案模板；我们的一条流水线从市场调研 → 品牌 → 文案 → **图** → **成片** → 日历 → 合规，产物直接可发。
- **媒体引擎三级降级，永不空场。** 生图 flux→turbo→本地渐变，LLM 限流快速换备用模型→确定性 mock，画质质检不合格自动重绘——**任何网络/配额状况下都能交付成片**，这是可上线产品与 demo 的分水岭。
- **合规体检是我们踩出来的差异化。** 调研确认 8 家竞品 0 家覆盖；这是跨境卖家最痛的坑（78% 搞不定、近 40% 首年被限权/封号），也是大厂「不敢做」的脏活。
- **成本账透明到分。** 每次运行在 data/runs 真实记账，前端「成本」页签直接看：12 次全流程 ¥1.23（媒体引擎零 Key 全免费）。对照 UGC 外包 $45-212/条、代运营 ¥5k-30k/月——1/100 量级。

## 4. 技术亮点（1 分钟，评委常问）

1. **Agent 图谱执行器**：11 步状态机 + append-only 事件日志（每步落盘，评审可复核 `data/runs/*.json`）。
2. **上下文接力**：每步工件注入下游 context——成片剪辑师忠实消费分镜导演的脚本，合规体检审的是真实产出。这是行业 demo 常见的「各步独立、伪协作」的正解（交叉评测 P0 批评的修复）。
3. **媒体工程**：Pollinations flux 免费生图（三级降级）+ edge-tts 多语言配音（声线跟随市场）+ 自研 ffmpeg 合成层（2x 超采样 Ken Burns / xfade / 双语字幕烧录 / whoosh 声音设计 / BGM ducking 侧链压缩）+ **vision 模型逐张质检生图**。
4. **可靠性设计**：推理模型偶发不输出 JSON → 3 次重试 + 结构校验 + 上游分镜兜底 + 确定性 mock；生图全挂本地渐变兜底——**全流程永不中断**。

### 附：Q&A 预案
- **「视频是 AI 生成的还是幻灯片？」** → 旁白/分镜/字幕/运镜全部 AI 生成，画面由 AI 生图 + 程序化运镜合成，AI 视觉质检逐张把关。这是 3 毛成本下的正确工程取舍；接 Seedance i2v（0.7 元/5s）即可升级为真视频片段，架构已预留（docs/07）。
- **「合规体检准确性？」** → 演示级规则库 + LLM 审查，覆盖广告法绝对化用语/各市场文化禁忌；v3 规划接法规库检索。核心是**行业唯一把这个环节产品化了**。
- **「怎么盈利？」** → 按次订阅（免费 1 次/天 → ¥49/月 30 次），单次成本 ≈¥0.3，毛利 >99%；对标代运营月费 1/100 定价锚点。
- **「生图为什么免费还能用？」** → Pollinations 开放接口 + 本地 ffmpeg 渲染 + 微软 Edge 神经语音，全部无 Key 资源；有预算可无缝切付费 API 提升画质/速度（.env 一行配置）。
