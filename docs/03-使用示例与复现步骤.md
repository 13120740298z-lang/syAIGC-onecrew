# 使用示例与复现步骤

> 评审复核指引：以下每一步都可以在本机复现。启动方式见 README「一键运行」。

## 一、复现步骤（3 步）

```bash
# 1. 安装依赖（首次）
npm run setup

# 2.（可选）配置真实模型：复制 server/.env.example 为 server/.env，填入 Key
#    不配置则自动进入演示模式，功能完整可跑

# 3. 启动
npm start          # → http://localhost:8787
```

## 二、使用示例（可直接照抄到输入框）

### 示例 1 · 一键出海内容包（核心演示，约 3-5 分钟）

```
我的产品是智能保温杯，316不锈钢12小时保温，想卖日本，帮我出全套出海内容
```

预期过程：
1. 助手确认启动「出海内容包工作流」，右侧工作台出现 7 步时间线；
2. 「市场快研」执行约 30-60 秒 → 产出《市场快研报告》工件；
3. 流程在「市场选择确认（人工）」挂起，出现 **✓ 批准 / ✕ 驳回** 按钮（对应截图 01）；
4. 点批准 → 依次完成品牌声音 → 五平台文案 → 提示词 → 日历 → 合规体检 → 状态「已完成」；
5. 切到「工件」Tab：6 个工件可预览、可下载（对应截图 02/04）。

### 示例 2 · 驳回路径（人工否决权）

同示例 1，但在确认点点 **✕ 驳回终止**：
预期：状态变「已取消」，确认按钮消失，日志留痕"用户驳回，流程终止"，后续步骤不再执行（对应截图 03）；可点「↻ 重跑」生成全新运行记录。

### 示例 3 · 单技能直调

```
帮我做一次北美市场的快研，产品是宠物智能喂食器
```
预期：路由器命中「市场快研」技能，单步执行并产出报告工件。

### 示例 4 · 技能卡直调

点左栏任意技能卡（如 🎙️ 品牌声音官）→ 输入框自动填入模板 → 补全产品名发送。

### 示例 5 · 自由对话

```
出海亚马逊和独立站，新手先做哪个？
```
预期：流式回复，不触发工作流。

### 示例 6 · 真·广告成片（视频工厂，总决赛核心演示，约 8-12 分钟）

```
我的产品是便携折叠电热水壶，折叠后仅手掌大，想卖日本，帮我出全套出海内容包+广告成片
```

预期过程：
1. 工作流 11 步推进：市场快研 → 人工确认 → 品牌声音 → 五平台文案 → 提示词 → **AI 直出配图（3 张真实 JPG）** → 英文旁白 → 分镜导演（JSON）→ **真·视频成片** → 内容日历 → 合规体检；
2. 成片步骤自动执行：逐镜 AI 生图（flux→turbo→本地渐变三级降级）→ AI 视觉质检（不合格自动重绘）→ edge-tts 配音（日本市场自动用日语声线）→ ffmpeg 电影感合成（运镜/转场/音效/双语字幕）；
3. 产出 **两个 MP4**（16:9 横版 1080p + 9:16 竖版）+ 封面图，点击工件行 → 内置视频播放器直接播放、可下载；
4. LLM 被限流时文本技能自动降级演示模式（界面明示），媒体管线照常产出真实成片——不阻塞。

单技能直调（跳过工作流）：

```
给我的露营氛围灯做一个 TikTok 广告视频，要真实成片
```

依赖：ffmpeg（WinGet `Gyan.FFmpeg`）+ Python edge-tts（`pip install edge-tts`）。

### 示例 7 · 演示模式（无 Key 复核）

将 `server/.env` 中 `LLM_API_KEY` 置空并重启 → 左下角与顶栏显示"演示模式"，重复示例 1 全流程照常（秒级完成，确定性产出）。
