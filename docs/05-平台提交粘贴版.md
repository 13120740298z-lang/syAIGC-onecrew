# 平台提交粘贴版（复制到赛事平台"提交/描述"栏即可）

---

**项目名**：OneCrew · 一人出海 AIGC 内容官（OneCrew — Your AI Content Crew for Going Global）

**赛道**：Q1W3 第三轮 AIGC 技术赛道 · Wave 3: Agents · **方向一：AI 工具 / Agent 方向**

**一句话**：面向一人公司（OPC）的对话式 AIGC 出海内容智能体——用户说一句"我的产品是XX，想卖XX"，六位 AI 队友接力完成「市场快研 → 人工确认 → 品牌声音 → 五平台文案 → 图像提示词 → 7天内容日历 → 合规体检」，产出一套可直接落地的出海内容包；每一步可视、可停、可重跑、可复核。

**仓库（含可运行代码/技能工作流/提示词/运行留痕/截图）**：
https://github.com/13120740298z-lang/syAIGC-onecrew

**一键运行**：`npm run setup && npm start` → http://localhost:8787 （无模型 Key 自动进入演示模式，全流程可跑；密钥仅存服务端，前端零泄漏）

**核心能力**：
- 一键「出海内容包」7 步工作流（agents/onecrew.agent.json），含**人工确认点**（批准继续/驳回终止）
- 六大独立技能（skills/*.json 文件化，引擎运行时真实加载）：市场快研 / 品牌声音 / 文案流水线 / 提示词工坊 / 内容日历 / 合规体检
- 状态机执行器（对齐 L10 规格）：步骤级 SSE 进度、取消/重跑、runs 不可变留痕，评审可直接打开 data/runs/*.json 复核
- 工件系统：市场报告(MD)、品牌声音档案(JSON)、五平台文案包(MD)、MJ/即梦/SD 提示词(MD)、7天日历(CSV 带 BOM)、合规清单(MD)
- 双 Provider 降级 + H8 本地安全闸

**使用示例**（复制进输入框即可）：
```
我的产品是智能保温杯，316不锈钢12小时保温，想卖日本，帮我出全套出海内容
```

**与前两轮相比的关键更新（Wave 3 新增）**：Wave1 Specs（需求确认单+11节设计规格，docs/01、docs/02）与 Wave2 Skills（六技能提示词与工作流文件，skills/）基础上，本轮交付**可运行的完整智能体系统**：①对话编排引擎（豆包式流式对话+意图路由）②状态机执行器（人工确认/取消/重跑/留痕）③工件系统（预览+导出）④双 Provider 降级 ⑤安全闸。一句话：前两轮证明"知道该做什么"，本轮证明"真的能跑、能交付、可复核"。
