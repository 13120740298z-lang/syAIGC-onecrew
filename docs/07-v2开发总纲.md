# OneCrew v2 开发总纲（2026-09-02 定稿）

## 0. 结论先行
- 目标：把 OneCrew 从「6 技能文档流水线」升级为「8 智能体端到端内容工厂」——真正产出 **AI 产品图 ×4 + 15 秒竖屏带货短视频成片（TTS 旁白 + 字幕 + BGM）**，并部署公网 Demo 供评委点开即玩。
- 差异化主打（三层递进）：
  1. **端到端出成品**：唯一一条 prompt 跑完「调研→文案→图→视频→日历→合规」的 agent 小队（同台对手最多到文档为止）；
  2. **行业唯一合规体检**：广告法/文化禁忌体检环节，十几家竞品无一做（调研确认）；
  3. **成本账**：单次全流程 ≈1.2 元（LLM+图+TTS），外包月费 1/100 以下，从 data/runs 真实记账。

## 2. 调研结论要点（三路 agent）
- **图片**：火山方舟 Seedream 4.0（0.2 元/张 2K，OpenAI 兼容 `POST /api/v3/images/generations`，URL 24h 过期须立刻下载）；备选 SiliconFlow（Kolors 免费 / Z-Image-Turbo 0.10 元）。
- **视频（可选高配）**：火山 Seedance 1.0 lite i2v（≈0.7 元/5s，异步任务 `POST /contents/generations/tasks` → 轮询）。
- **TTS**：node-edge-tts 免费（开发/演示）→ SiliconFlow CosyVoice2（0.5 元/万字符，合规兜底）→ MiniMax speech-02-turbo（2 元/万字符，顶级质量）。
- **合成**：spawn + ffmpeg-static + `-filter_complex_script`；zoompan 需 `s=1080x1920` 显式；xfade offset 累计；中文 ASS 字幕 Linux 需 fonts-noto-cjk；fluent-ffmpeg 弃维勿用。
- **部署**：Railway/Render/HF/CF 免费档全部因大陆被墙出局。首选腾讯云/阿里云**香港轻量**（¥288/年，免备案直连）；备选 Sealos 国内节点（¥25-32/月）；兜底 cpolar 隧道。
- 单次全流程成本：基础档 ≈0.82–1.2 元；高配（Seedance 3 段）≈2.9–3.3 元。

## 3. v2 架构：8 智能体流水线
```
🔍 市场快研 → ⏸ 人工确认 → 🎙️ 品牌声音 → ✍️ 五平台文案 → 🎨 图像提示词
→ 🖼️ 视觉工坊(NEW: 真生成图×4) → 🎬 短片导演(NEW: TTS旁白脚本+ffmpeg成片) → 📅 内容日历 → 🛡️ 合规体检
```
新工作流步骤顺序（视觉工坊放提示词之后、短片导演需要图做输入/参考；日历与合规最后复核全链路）：
`market-scan → confirm → brand-voice → copy-studio → visual-prompt → visual-studio → video-director → content-calendar → local-check`

### 上下文接力（修复 chozzc 批评的核心 bug）
runner 在每步完成后把上游工件摘要注入下游 params.context（run 级共享 ctx）：
- brand-voice ← market-scan（差异化角度、平台优先级）
- copy-studio ← brand-voice(tone/vocab/slogan) + market-scan
- visual-prompt ← copy-studio 的 hook + brand-voice 视觉关键词
- visual-studio ← visual-prompt 的提示词（真实生图）
- video-director ← visual-studio 的图片 + copy-studio 的 hook/CTA（旁白脚本要引用卖点）
- content-calendar ← 全部前序（日历引用各平台文案与视频）
- local-check ← 全部前序（体检对象是实际产出内容）

### 两个新技能定义
- `visual-studio`（output_type: images）：调 Seedream/SiliconFlow 生成 4 张产品图，落盘 exports/，工件 = 图片 + 生成参数清单 MD。无 key 降级：用 SVG/占位图合成本地「构图小样」并明示演示模式。
- `video-director`（output_type: video）：① LLM 生成 15s 旁白脚本（分镜+字幕句）② TTS 旁白 ③ ffmpeg 合成 1080x1920 MP4（4 图 Ken Burns + xfade + 旁白 + ASS 字幕 + BGM ducking）④ 工件 = MP4 + 分镜脚本 MD。无 key 降级：静音/合成音的「动态分镜小样」并明示。
