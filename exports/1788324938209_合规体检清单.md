## 1. 広告コンプライアンス（日本・景品表示法／薬機法／特定商取引法に基づく一般的注意点）

- [x] **絶対的表現の禁止**  
  「最高」「日本一」「業界No.1」「完全」など、客観的な根拠がない絶対的・優位性を暗示する表現は景品表示法違反となる可能性がある。FoldOneのブランドボイスで避けるべき語彙（best, revolutionary, perfect, #1, 100%等）は日本語でも同様に避ける。  
  → 例：×「世界最高のスタンド」 → ○「静かにデスクを整えるスタンド」

- [x] **価格表示のルール**  
  税込価格を明示（「2,980円（税込）」）。「送料無料」と表示する場合は実際に無料であること。「今だけ20%OFF」など割引率を表示する場合、比較対象となる通常価格（直近の販売価格）を併記し、実際の値引き期間を明示する必要がある。  
  → 参考：経済産業省「価格表示ガイドライン」

- [x] **販売促進の開示（ステルスマーケティング禁止）**  
  インフルエンサーに依頼するレビュー・投稿は広告であることを明示（「#PR」「#広告」「#プロモーション」等）。消費者庁の「ステルスマーケティング規制」に注意。  
  → 例：FoldOneのTikTokインフルエンサー投稿には必ず「#PR」を付ける

- [x] **性能・効果の誇大表示禁止**  
  「1秒で開く」は事実だが、「1秒で仕事が終わる」「集中力が2倍になる」など、製品本来の効能を超える効果を暗示する表現は不可。  
  → ブランドボイスに沿った「静かな効率」「落ち着いたデスク」のトーンで表現を抑える。

- [x] **比較広告のルール**  
  競合製品との比較を行う場合、客観的なデータ（自社調査・第三者機関の検証）と出典を示す必要がある。不作成の「競合より速い」は禁止。  
  → 例：比較するなら「競合A（公表値）の開く時間は約2秒、FoldOneは約1秒（自社測定）」と具体的数値と出典を明記。

## 2. 文化的禁忌（日本市場向けチェック）

- [x] **色の禁忌**  
  - **白**：葬儀・死を連想させる（白い花束、白い封筒）。製品のベージュ・グレージュ・ナチュラルは問題ないが、白を基調にした画像やパッケージは避けるのが無難。  
  - **黒**：喪服の色だが、ガジェットでは一般的。問題は少ないが、和室の写真では重すぎる印象を与えないように。  
  - **赤**：縁起の良い色（神社・お祝い）だが、過度な使用は派手すぎる。FoldOneのカラーは赤を含まないため問題なし。

- [x] **数字のタブー**  
  - **4**（し、死）・**9**（く、苦）は不吉。製品の価格設定（2,980円は4を含まないためOK）、数量表記（在庫数など）に使わない。  
  - 7日間のキャンペーンなどは問題ない。

- [x] **ジェスチャー・ボディランゲージ**  
  - 親指を立てる「OK」サイン（日本では「お金」の意味）は、文脈によっては失礼にならないが、製品広告では避ける方が安全。  
  - 指を指す行為（相手を指さす）は失礼。製品の使い方を示す手の動きは、掌を上に向けて優しく案内するように。

- [x] **宗教的配慮**  
  - 神道・仏教に関連するシンボル（鳥居、仏像、お経）を製品画像に入れない。  
  - 和室の写真（畳、障子）は文化的に好ましいが、神社仏閣の境内で撮影したような背景は避ける（宗教利用の誤解を避ける）。

- [x] **ユーモアの尺度**  
  - 日本では「自虐的」「控えめ」「共感型」のユーモアが好まれる。大声で笑うようなギャグや、他人を貶す冗談はNG。  
  - FoldOneのトーン（calm, precise, minimal）に合う、軽い気づきや共感を誘う表現がベター（例：「机の乱れが、仕事の乱れ？」）。

- [x] **「チープ」という表現**  
  - 競合を「安っぽい」と直接表現するのは避ける。代わりに「FoldOneのマットな質感は、プラスチックとは違う落ち着きを」とポジティブに。

- [x] **「磁気」に関する迷信**  
  - 日本では「磁気ネックレス」など健康グッズのイメージが強いが、スマホスタンドは問題ない。ただし、医療機器としての効能を示唆する表現は禁止。

- [x] **「1秒」の誇張**  
  - 実際の開く時間を計測し、動画で実証するのが望ましい。誇張して「0.5秒」などとしない。
