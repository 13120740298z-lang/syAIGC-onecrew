# 市場クイックリサーチ：スマート保温ボトル（日本市場）

*注：数値はデスクトップリサーチによる推定値であり、正確な統計ではありません。*

## 1. 市場規模とトレンド

- 日本の保温ボトル市場全体は約1,000〜1,200億円規模（推定）。そのうちスマート保温ボトル（温度表示・飲水リマインダー・アプリ連携）は**50〜100億円**の新興セグメントと推定されます。
- 年間成長率は**15〜20%**（推定）。健康意識の高まり、スマートヘルスケアの普及、在宅・オフィスでの自分健康管理ニーズが牽引。
- 象印・タイガー・サーモス等の大手は保温性能・ブランドで強いが、**スマート機能では未開拓**な領域が残っている。

## 3. 競合と差別化

### 3-1 競合の3次元整理

- **価格帯**
  - 従来の高級保温ブランド（象印 / タイガー / サーモス）：2,000〜5,000円
  - 温度表示＋アプリ連携などのベーシックスマート品：8,000〜15,000円
  - 温度コントロール型（Ember等）：12,000〜20,000円以上

- **売上の共通点（二番煎じリスク）**
  - 真空断熱ステンレス構造、長時間保冷・保温
  - LED温度表示、飲水リマインダー
  - アプリでの飲水記録・健康管理
  - USB充電式、センサー内蔵

- **見落とされている角度**
  - 日本茶の「適温」への最適化（煎茶・ほうじ茶・緑茶で飲みごろ温度が異なる）
  - 通勤・オフィスでの“静音性”や“机の上で邪魔にならない設計”
  - 日本の夏に強い「保冷重視」設計
  - 中元・歳暮ギフト市場に特化したカスタマイズ包装

### 3-2 差別化切入角度（具体的なコンテンツ題材）

**角度A：「日本茶の適温」特化型スマート保温ボトル**

- 機能：煎茶・ほうじ茶・緑茶など茶種に応じた最適温度をプリセットし、飲み頃になるとLEDで通知。アプリで茶種別の温度履歴を管理。
- コンテンツ例：
  - TikTok：10秒動画「日本茶の正しい温度、知ってる？」で温度表示画面を見せる
  - Instagram：茶道家や茶空間とのコラボ投稿「#お茶の時間」
  - X：ほうじ茶の適温を当てる投票企画を行い、リプライで拡散

**角度B：「会社員の水分チャレンジ」習慣化特化**

- 機能：体重・活動量・気温から1日の水分量を算出して通知。企業健康保険や健康管理アプリと任意連携（データは要同意）。
- コンテンツ例：
  - TikTok：ハッシュタグ「#水分補給チャレンジ」で7日間の継続動画
  - YouTube：オフィスデスクで実測した「30分の作業中に人はどれだけ飲むのか」実験動画
  - LINE公式アカウント：毎日10時に水分リマインドを配信し、クーポンで特典を付与

**角度C：「夜間モード」で睡眠に配慮した健康管理**

- 機能：夕方以降はアプリの画面をダークモードにし、ブルーライトを抑制。飲水量と睡眠メモを一体管理。

## 4. プライシングと発売戦略

- 提案価格帯：
  - 主力SKU：**9,800円（税込）**
  - アップグレード版（茶温プリセット・金属ボディ等）：**13,800円〜15,800円**

- 根拠：
  - Ember等のハイエンド品より30%以上低く、従来からのステップアップ購入がしやすい
  - 日本の一般保温ボトル（2,000〜5,000円）と比べると“健康投資”として納得感のある価格
- 発売戦略：
  1. **Makuake**で先行クラウドファンディングを行い、価格帯・売れ筋機能を検証

  3. 健康系・TikTok/YouTubeインフルエンサーに先行PR品を配布
  4. Instagramで「#スマートボトル」のUGC（ユーザー投稿）キャンペーンを実施
